# 🐼 Pandas na Prática

Repositório criado para registrar meus estudos e práticas com a biblioteca **Pandas**, utilizando **Python** através do vídeos disponíveis do 
Téo Me Why
Aqui estão os exercícios, exemplos e práticas desenvolvidos durante meu processo de aprendizagem e revisão dos principais recursos da biblioteca.

## 📚 Conteúdos praticados

* Importação e utilização do Pandas
* Series e DataFrames
* Leitura e manipulação de arquivos CSV
* Seleção e filtragem de dados
* Tratamento e organização de dados
* Ordenação de dados
* Agrupamento com `groupby`
* Análise e exploração de dados

## 🛠️ Tecnologias

* Python
* Pandas
* VS Code
* Git e GitHub

Consolidar meus conhecimentos em manipulação e análise de dados com Pandas por meio de prática contínua e exercícios aplicados.
